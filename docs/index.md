# PokeData

Look up Pokemon, types, evolution chains, moves, abilities, items, berries, locations, machines,
regions, pokedexes, egg groups, growth rates, stats, and natures from
[PokeAPI](https://pokeapi.co) directly on the Grasshopper canvas — with audio cries, type
matchups, generative computational geometry, topological evolution graphs, and
battle-optimization solvers — no auth required, since PokeAPI is fully public.
