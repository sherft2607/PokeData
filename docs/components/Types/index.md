# Types

| Component | Description |
|---|---|
| [Get Type](GetType.md) | One type's damage relations to/from every other type, plus its associated Pokemon |
| [Get Type Matrix](GetTypeMatrix.md) | The full 18x18 type-effectiveness matrix in one component |
| [Type Matchup](TypeMatchup.md) | Just the outgoing damage relations for a type, split into 2x/0.5x/0x lists |
| [Dual Type Matchup](DualTypeMatchup.md) | A two-type Pokemon's true combined defensive multipliers |
