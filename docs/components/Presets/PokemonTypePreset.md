# Type Name

A `GH_ValueList` preset with a fixed dropdown of the 18 elemental Pokemon types, so you don't have
to type type names by hand.

## Inputs

None.

## Outputs

| Name | Type | Description |
|---|---|---|
| Type Name | text | The selected elemental type's API string value, e.g. `"fire"` |

## Notes

Wires directly into [Get Type](../Types/GetType.md)'s `Type Name` input.
